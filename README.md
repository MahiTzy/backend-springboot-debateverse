## Getting Started
1. Install the JDK and build tool required by the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/backend-springboot-debateverse.git
   cd backend-springboot-debateverse
   ```
3. Review application configuration and configure the required database and external services.
4. Run with the Maven wrapper if included (`./mvnw spring-boot:run`) or use the configured build tool.
